Project Title

TimeLux Watches - Online Watch Store

Project Description

TimeLux Watches is a simple no-code e-commerce website created using Wix. The website is designed for selling stylish and affordable watches online. It allows customers to view watch products, check prices, read product descriptions, and interact with the shopping cart.

The main purpose of this project is to demonstrate how a no-code/low-code platform can be used to design and develop a simple e-commerce website without writing code.

Platform Used

The website was created using Wix, a no-code website builder that allows users to design websites using templates, drag-and-drop tools, and built-in e-commerce features.

Website Pages

The website includes the following pages:

1. Home Page
    The homepage includes the store name, a welcome message, a banner image, and a Shop Now button.
2. Products Page
    The products page displays watch products with images, prices, descriptions, and Add to Cart buttons.
3. About Page
    The about page explains the purpose of TimeLux Watches and its mission.
4. Contact Page
    The contact page includes email, phone number, location, and a contact form.
5. Cart Page
    The cart page allows customers to view products added to the cart.

Features Implemented

* Modern and responsive website design
* Homepage with store name and welcome message
* Product page with at least five products
* Product images, prices, and descriptions
* Add to Cart button for products
* About page with store description and mission
* Contact page with contact information and form
* Cart interaction for basic e-commerce functionality
* Simple navigation menu

Challenges Faced

Some challenges faced during the project included choosing a suitable website design, organizing the product information, selecting appropriate images, and making sure the website pages matched the assignment requirements.

Another challenge was learning how to use Wix tools to edit pages, add products, and test the cart interaction.

Lessons Learned

Through this project, I learned how to create a simple e-commerce website using a no-code platform. I also learned how to add products, organize website pages, customize website content, and publish a live website.

I also learned how to document a project using GitHub Markdown and how to organize a repository with a README file and screenshots.
